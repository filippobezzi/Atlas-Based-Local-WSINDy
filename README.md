# Atlas-Based-Local-WSINDy
Atlas-based weak-form PDE discovery with tangent-space operator pruning.

Synthetic PDE discovery benchmarks often conflate generative truth with statistical identifiability. Because observations sample only a restricted subset of the solution space, multiple PDEs may be observationally equivalent on the sampled support. We propose a **local geometric framework** that estimates the **data-supported solution manifold** and identifies only those differential operators whose action is statistically distinguishable within local neighborhoods.

## Research Question
Given a phenomenon, can the local geometry of observed data provide valid constraints on the differential operator of the underlying dynamical process' PDE?

The SINDy algorithm is a method that from an arbitrary library of operators looks for the sparse linear combination that best fits the data. However it is subject to some problems as described in the following example.

Suppose the data were generated by a Burgers'-like process, with PDE

$$
u_t = -u u_x + \nu u_{xx}.
$$

A SINDy-style method might fail to recover the $u_{xx}$ term if:
* the sampling is too coarse to resolve diffusion;
* the initial condition does not excite modes where diffusion matters;
* the observation window is too short;
* the noise level overwhelms second derivatives;
* the solution lies near a reduced manifold where advection and diffusion effects are collinear;
* the regression library contains alternative terms that produce nearly identical predictions on the sampled support.

The problem is that under any of the above sampling designs, Burgers’ equation is not statistically distinguishable from a lower-order transport model, a reduced effective model, or another PDE with nearly identical action on the observed data manifold.

We argue that, given some known generating PDE and the sampling protocol, it would be useful to know which other PDEs are observationally equivalent or nearly equivalent on the sampled data. In practice we would like the algorithm to return an uncertainty set, equivalence class, or model confidence ranking, not just one symbolic equation.

Considering the above example, the goal is to build an algorithm that is able to output something like:
1. Locally identifiable terms
    * $u_x$: strongly supported
    * $u u_x$: moderately supported
    * $u_{xx}$: weakly supported
    * $u_{xxx}$: not estimable
2. Equivalence classes
    * Model A and Model B are indistinguishable on sampled support.
    * Model C is distinguishable only in high-curvature regions not well sampled.
3. Sampling diagnostics
    * The data do not sufficiently excite directions needed to separate diffusion from nonlinear advection.
    * Additional initial conditions or higher-resolution samples are required to break the degeneracy.
4. Local-to-global consistency
    * Terms are stable across charts, or only appear in certain regions.
    * Coefficients are globally consistent, locally varying, or not identifiable.

We attempt to frame PDE discovery as statistically constrained model discrimination over a data-supported manifold. Where geometry is used to determine which differential operators are locally meaningful and which PDE models are distinguishable under the sampling design.
